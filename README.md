# 🤖 Machine Learning with Scikit-Learn

A collection of beginner-friendly Machine Learning projects built using **Python** and **Scikit-learn**. This repository demonstrates the implementation of various **Regression algorithms** through real-world datasets using Jupyter Notebooks.

---

# 📖 Overview
This repository is designed to help learners understand the fundamentals of Machine Learning by implementing regression models with the Scikit-learn library.

Each notebook explains the complete workflow, including data preprocessing, model training, prediction, and performance evaluation.
